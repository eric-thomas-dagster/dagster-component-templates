# HybridKnowledgeSearchQueryComponent

"Ask a question from a run": one asset that calls an already-registered
`HybridKnowledgeSearchResource`'s `.search(query, top_k, hops, mode)` and
reports the results as run metadata, so a hybrid (vector + graph) knowledge
base -- see [`hybrid_knowledge_search_server`](../hybrid_knowledge_search_server/README.md)
-- can be tested from Dagster+ without writing any client code.

Requires a `HybridKnowledgeSearchServerComponent` already registered under
`hybrid_resource_key` in the same code location. This component only
references that resource via Dagster's own resource-injection
(`required_resource_keys`) -- it has no vector/graph client code of its own.

## Launchpad run config

Every static field (`query_text`/`top_k`/`hops`/`mode`) can be overridden per
run via `HybridKnowledgeSearchQueryRunConfig`, so the same asset can answer a
different question from a Launchpad run without editing the component's own
YAML:

```yaml
ops:
  support_kb_ask:
    config:
      query_text: "How do I reset a customer's password?"
      top_k: 5
      hops: 1
      mode: hybrid
```

`query_text` must be set either statically on the component or via this run
config for every run -- a run with neither fails clearly.

## Run metadata

The asset reports `hits` (JSON `{passages: [{chunk_id, text, score, source,
paths}], triples: [{subject, relation, object, chunk_id, evidence}]}`),
`entities_matched` (the sorted set of every triple's subject/object),
`passage_count`, `triple_count`, and the effective `query_text`/`mode`/
`top_k`/`hops` used for the run.

## Example YAML

```yaml
type: dagster_community_components.HybridKnowledgeSearchQueryComponent
attributes:
  asset_name: support_kb_ask
  hybrid_resource_key: hybrid_search
  query_text: "How do I reset a customer's password?"
  top_k: 5
  hops: 1
  mode: hybrid
```

## Inputs and Outputs

| | Type | Description |
|-|------|-------------|
| Input | none | Reads from an already-registered `HybridKnowledgeSearchResource`, not a Dagster asset input |
| Output | none | Reports `hits`/`entities_matched` and counts as run metadata |
