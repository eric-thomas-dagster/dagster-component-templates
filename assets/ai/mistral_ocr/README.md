# Mistral OCR

Native Mistral AI Document OCR via `client.ocr.process` — a dedicated OCR model, not a chat-completions call dressed up as one. Sibling of `ocr_extractor` (local Tesseract, images only), but trained specifically on documents: multi-column layouts, tables, embedded figures, and multi-page PDFs come back as structured markdown.

```yaml
type: dagster_component_templates.MistralOcrComponent
attributes:
  asset_name: invoice_text
  upstream_asset_key: incoming_invoices
  input_column: file_path
  output_column: markdown
  model: mistral-ocr-latest
```

## Input handling

`input_column` can hold either a public `http(s)://` URL or a local file path — `input_kind` (default `auto`) picks the right API shape per row from the file extension:

| Input | API shape used |
|---|---|
| Remote URL, document extension (`.pdf`/`.doc`/`.docx`/`.ppt`/`.pptx`) | `{"type": "document_url", "document_url": "<url>"}` |
| Remote URL, image extension | `{"type": "image_url", "image_url": "<url>"}` |
| Local image file | Read + base64-encoded inline as a `data:` URI, sent as `image_url` — no upload needed. |
| Local document file | Uploaded via `client.files.upload(..., purpose="ocr")`, exchanged for `client.files.get_signed_url(...)`, consumed as `document_url` — OCR's `document_url` type has no inline-base64 form, unlike `image_url`. |

Set `input_kind: document` or `input_kind: image` to force the classification instead of relying on the extension.

## `ocr_extractor` vs `mistral_ocr`

| | `ocr_extractor` | `mistral_ocr` |
|---|---|---|
| Engine | Local Tesseract (`pytesseract`) | Mistral's hosted OCR model |
| Cost | Free, local compute | Per-page API cost |
| Multi-page PDFs | No — single image files only | Yes, native |
| Tables / multi-column layout | Poor — flat text extraction | Structured markdown |
| Network required | No | Yes |

Pick `ocr_extractor` for simple, high-volume, already-single-image inputs where Tesseract's accuracy is sufficient and a network call per row isn't worth it. Pick `mistral_ocr` for real-world documents — scanned forms, invoices, multi-page PDFs — where layout and table structure matter.

## Sister components

- `ocr_extractor` — local Tesseract OCR, images only.
- `mistral_llm` — Mistral chat completions (summarization, classification, etc. on the markdown this component produces).
- `document_summarization` — pairs well downstream of this component's markdown output.
