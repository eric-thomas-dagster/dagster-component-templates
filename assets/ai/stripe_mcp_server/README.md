# StripeMcpServer

A local **stdio MCP server** that proxies to Stripe's own hosted MCP server
(`https://mcp.stripe.com`), authenticated with a static **Agent API key** — no OAuth, no token
refresh, no sign-in CLI. Confirmed directly against Stripe's docs (docs.stripe.com/mcp): plain
secret/restricted keys are rejected here — create an API key with the **Agent** badge (Dashboard
→ Developers → API keys) and set it in the env var `api_key_env_var` names.

```yaml
type: dagster_community_components.StripeMcpServerComponent
attributes:
  resource_key: stripe_mcp
  api_key_env_var: STRIPE_AGENT_API_KEY
```

Then, in any MCP-aware component (anthropic_agent / openai_agent / litellm_agent / gemini_agent /
agentic_pipeline) instead of an inline `server:` spec:

```yaml
server_resource_key: stripe_mcp
```

## Generic tool passthrough, not one tool per Stripe operation

Stripe's hosted MCP server exposes a large, evolving catalog of Stripe API operations. Rather than
hardcoding a tool per operation (which would drift the moment Stripe adds or renames one), this
proxy exposes exactly two generic tools:

- `list_remote_tools` — lists the Stripe MCP tools currently available (name + description).
- `call_remote_tool(tool_name, arguments)` — calls one by name with a JSON-object of arguments.

## Connected accounts (`stripe_account_env_var`)

To act on behalf of a connected account, set `stripe_account_env_var` to an env var holding the
connected account id (`acct_...`) — sent as the `Stripe-Account` header, per Stripe's own MCP docs.

## `allow`

Restrict which Stripe MCP tools are callable, independent of what Stripe's hosted server exposes:

```yaml
allow:
  - list_customers
  - list_charges
```

## Per-server usage guidance (`instructions`)

Set `instructions` here, once, instead of pasting the same guidance into every agent that uses
this server via `server_resource_key`. The litellm/openai/anthropic/gemini agent components read
it off the resolved resource and append it to their system prompt under a heading with this
resource's `resource_key` name.
