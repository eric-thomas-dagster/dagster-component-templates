# naive_bayes_model

Fit a Gaussian Naive Bayes classifier (sklearn `GaussianNB`). **Gaussian only** — despite the name, this component does NOT support Multinomial or Bernoulli variants; there is no `variant` field. Classification only — sklearn ships no Gaussian-NB regressor, so `task_type='regression'` always raises. Appends a `predicted` column and/or per-class `predicted_proba_<class>` columns to the output DataFrame.

## Ingestion

Two ways to get the rows in, set exactly one:

- **`upstream_asset_key`**: the usual Dagster way -- point at any asset producing a DataFrame with `feature_columns` + `target_column`.
- **`source: {kind: warehouse_query, resource_key: ..., sql: ...}`**: pull rows directly via SQL, no upstream asset required. Works out of the box with `duckdb_resource` and any resource exposing `.get_engine()`/`.get_connection()`, or a bare SQLAlchemy connection string via `database_url_env_var` when no Dagster resource is registered.

## `execution_mode: sql` -- predict server-side (Databricks-only, predict-only)

Unlike every other component in this session's SQL-execution-mode family, **only `databricks` is offered here, and it never trains anything** -- this is a deliberate, narrower design, not an oversight:

- **BigQuery ML has no `NAIVE_BAYES` model type at all.**
- **Snowflake's `SNOWFLAKE.ML.CLASSIFICATION` is AutoML** -- it picks its own algorithm internally and never guarantees (or even exposes) Naive Bayes specifically.

Offering either as "train a Naive Bayes here" would be the same misleading "exact equivalent" framing this session avoided by skipping `decision_tree_model` entirely. Databricks' predict-only branch is honest regardless of algorithm, since it never claims to train or BE any specific algorithm anywhere in this component family -- it just calls `ai_query()` against a `model_name` that must already be an existing, already-served Model Serving endpoint.

```yaml
type: dagster_component_templates.NaiveBayesModelComponent
attributes:
  asset_name: lead_quality_nb_sql
  source:
    kind: warehouse_query
    resource_key: databricks_resource
    sql: "SELECT * FROM raw.lead_features"
  execution_mode: sql
  sql_dialect: databricks
  output_table: analytics.lead_quality_nb
  model_name: lead_quality_nb_endpoint
  target_column: lead_quality
  feature_columns: [company_size, engagement_score]
```

## Output Columns

- `predicted` (if `output_predictions: true`, default): predicted label for each row
- `predicted_proba_<class>` (if `output_probabilities: true`, default): one column per class with predicted probability

type: dagster_component_templates.NaiveBayesModelComponent
