# neural_network_model

Fit a multi-layer perceptron (MLP) neural network using scikit-learn's `MLPClassifier` or `MLPRegressor` for classification or regression. `n_estimators` maps to the hidden-layer width (minimum 8); `max_depth` maps to `max_iter` (default 200). Features are auto-scaled with `StandardScaler`. Output is either predictions appended to the original DataFrame or a ranked feature-importance table.

## Ingestion

Two ways to get the rows in, set exactly one:

- **`upstream_asset_key`**: the usual Dagster way -- point at any asset producing a DataFrame with `feature_columns`/`target_column`.
- **`source: {kind: warehouse_query, resource_key: ..., sql: ...}`**: pull rows directly via SQL, no upstream asset required. Works out of the box with `duckdb_resource` and any resource exposing `.get_engine()`/`.get_connection()`, or a bare SQLAlchemy connection string via `database_url_env_var` when no Dagster resource is registered.

## `execution_mode: sql` -- train (or predict) server-side

Same 3-dialect asymmetry as `logistic_regression_model`/`gradient_boosting_model` -- and arguably the cleanest match in the whole family:

- **`bigquery`**: `CREATE MODEL ... OPTIONS(model_type='DNN_CLASSIFIER'|'DNN_REGRESSOR', hidden_units=[N])` -- a real, exact algorithmic match (BigQuery's DNN model IS a neural network), supporting both task types.
- **`snowflake`**: `CREATE SNOWFLAKE.ML.CLASSIFICATION` -- a functional substitute for the same task, **not literally a neural net internally**, and **classification only**. `task_type: regression` + `sql_dialect: snowflake` raises a clear error; use `sql_dialect: bigquery` for regression.
- **`databricks`**: **predict-only**, arguably the most natural fit for this component of any in the family -- neural nets are typically trained via MLflow/AutoML and served as an endpoint on every platform anyway, not defined inline in SQL. `model_name` must be an already-served Model Serving endpoint.

`execution_mode: sql` only supports `output_mode: predictions`.

## Output Modes

- **`predictions`**: Returns the original DataFrame with a `predicted` column appended.
- **`probabilities`**: Also appends `proba_<class>` columns (classification only).

## Example YAML

```yaml
component_type: neural_network_model
description: Predict subscription renewal with a two-layer MLP.

asset_name: renewal_mlp_predictions
upstream_asset_key: subscription_features
target_column: renewed
feature_columns:
  - months_active
  - avg_monthly_usage
hidden_layer_sizes:
  - 128
  - 64
task_type: classification
output_mode: probabilities
group_name: renewal_models
```

## Metadata Logged

Regression: `r2_score`, `mean_absolute_error`, `n_estimators`, `train_rows`, `test_rows`.

Classification currently computes `accuracy`/`classification_report` internally but does not emit them as asset metadata (a pre-existing gap in the python-mode path, not something this session's changes touch).
