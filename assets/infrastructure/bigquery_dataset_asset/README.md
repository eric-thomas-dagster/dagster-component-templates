# BigQuery Dataset Asset Component

Create, ensure-exists, recreate, or delete a BigQuery dataset as a Dagster asset — the Airflow `BigQueryCreateEmptyDatasetOperator` / `BigQueryDeleteDatasetOperator` equivalent. Real `google-cloud-bigquery` client calls throughout.

```yaml
type: dagster_community_components.BigQueryDatasetAssetComponent
attributes:
  asset_name: bq/analytics_dataset
  credentials_path: "{{ env.GOOGLE_APPLICATION_CREDENTIALS }}"
  dataset_id: analytics
  location: US
  mode: ensure_exists
  labels:
    team: data-platform
```

`mode='ensure_exists'` (default) creates the dataset if missing and is a no-op otherwise (idempotent). `mode='recreate'` drops the dataset (honoring `delete_contents`) and creates it fresh. `mode='delete'` just drops it.

Pairs with [`bigquery_table_asset`](../bigquery_table_asset/) for table-level lifecycle and [`bigquery_value_check_asset`](../bigquery_value_check_asset/) for data-quality assertions, or [`bigquery_resource`](../../../resources/bigquery_resource/) for other components that just need a shared `BigQueryResource`.
