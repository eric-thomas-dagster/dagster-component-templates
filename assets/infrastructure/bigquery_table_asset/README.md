# BigQuery Table Asset Component

Create, ensure-exists, recreate, or delete an empty BigQuery table (explicit schema, optional time partitioning + clustering) as a Dagster asset — the Airflow `BigQueryCreateEmptyTableOperator` / `BigQueryDeleteTableOperator` / `BigQueryTableExistenceSensor` equivalent. Schema/DDL lifecycle only; it never loads rows — see [`sql_to_database_asset`](../../ingestion/sql_to_database_asset/) or [`bigquery_load_from_gcs_asset`](../../ingestion/bigquery_load_from_gcs_asset/) for loading data into the table this creates.

```yaml
type: dagster_community_components.BigQueryTableAssetComponent
attributes:
  asset_name: bq/orders_table
  credentials_path: "{{ env.GOOGLE_APPLICATION_CREDENTIALS }}"
  dataset_id: analytics
  table_id: orders
  mode: ensure_exists
  schema:
    - { name: order_id, type: STRING, mode: REQUIRED }
    - { name: order_date, type: DATE, mode: REQUIRED }
    - { name: amount, type: NUMERIC }
  table_partition_field: order_date
  cluster_fields: [order_id]
```

`mode='ensure_exists'` (default) creates the table from `table_schema` if missing (idempotent, never alters an existing table's columns). `mode='recreate'` drops and recreates it from `table_schema`. `mode='delete'` just drops it (`table_schema` not required for that mode).

Pairs with [`bigquery_dataset_asset`](../bigquery_dataset_asset/) for dataset-level lifecycle and [`bigquery_value_check_asset`](../bigquery_value_check_asset/) for data-quality assertions on the table's contents.
