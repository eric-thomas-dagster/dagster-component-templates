# BigQuery Value Check Asset Component

Run a scalar SQL query against BigQuery and assert the result matches an expectation — the Airflow `BigQueryCheckOperator` / `BigQueryValueCheckOperator` data-quality-check equivalent.

```yaml
type: dagster_community_components.BigQueryValueCheckAssetComponent
attributes:
  asset_name: bq/orders_row_count_check
  credentials_path: "{{ env.GOOGLE_APPLICATION_CREDENTIALS }}"
  deps: [bq/orders_table]
  query: "SELECT COUNT(*) FROM `my-project.analytics.orders`"
  expected_value: 0
  comparison: greater_than
```

Reads the first column of the first row of `query`'s result and compares it to `expected_value` via `comparison` (default `'equal'`), with an optional numeric `tolerance` for `equal`/`not_equal`. Raises and fails the run on a mismatch by default; set `fail_on_mismatch: false` to materialize anyway with `check_passed: false` in metadata, for a check meant to inform downstream logic rather than halt the pipeline.

Pairs with [`bigquery_dataset_asset`](../bigquery_dataset_asset/) and [`bigquery_table_asset`](../bigquery_table_asset/) for lifecycle, or [`rag_grounding_check`](../../ai/rag_grounding_check/)-style asset checks for a check wired as a Dagster `@asset_check` rather than its own asset.
