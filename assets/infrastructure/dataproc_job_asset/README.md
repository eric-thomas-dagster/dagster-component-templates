# Dataproc Job Asset

Submits a PySpark/Spark/Hive/Pig job to an existing Google Cloud Dataproc cluster and waits for completion -- the `DataprocSubmitJobOperator` equivalent from Airflow's Dataproc provider.

Unlike `dataproc_cluster_asset` (long-running infra), this is a true batch job: `submit_job` is called once per materialization, then the asset polls `get_job` until the job reaches a terminal state (`DONE`, `ERROR`, or `CANCELLED`), raising on failure and surfacing the job's driver output location on success.

## Example YAML

```yaml
type: dagster_community_components.DataprocJobAssetComponent
attributes:
  asset_name: etl_pyspark_job
  project_id: my-gcp-project
  region: us-central1
  cluster_name: etl-cluster
  job_type: pyspark
  main_python_file_uri: gs://my-bucket/jobs/transform.py
  args: ["--date", "2026-11-26"]
  deps: [etl_dataproc_cluster]
  group_name: infrastructure
  kinds: [gcp, dataproc]
```

## Job types

- **pyspark** -- requires `main_python_file_uri`. Optional `python_file_uris` (extra `.py`/`.zip`/`.egg` files), `jar_file_uris`, `file_uris`, `archive_uris`, `args`, `properties`.
- **spark** -- requires `main_jar_file_uri` or `main_class` (the latter needs the providing jar listed in `jar_file_uris`). Same optional fields as pyspark except `python_file_uris`.
- **hive** / **pig** -- requires `query_file_uri` or `query_list` (inline statements run in order). `continue_on_failure` keeps running subsequent queries after one fails; `script_variables` substitutes Hive/Pig variables into the query text.

## Requirements

A Spark/Hadoop/Hive/Pig job needs an existing Dataproc cluster to run on -- pair this with `dataproc_cluster_asset` (set `deps` to the cluster asset for correct ordering) or point `cluster_name` at a cluster managed outside Dagster.

## Authentication

Uses Application Default Credentials (ADC) by default -- Workload Identity, `GOOGLE_APPLICATION_CREDENTIALS`, or `gcloud auth application-default login`. Set `gcp_credentials_env_var` to an env var containing a service account JSON string to use explicit credentials instead.

```
google-cloud-dataproc
```
