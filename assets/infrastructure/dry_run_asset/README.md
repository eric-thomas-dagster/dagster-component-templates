# `DryRunAssetComponent` + `@dry_run` decorator

Run the compute, skip the write. Ideal for validating a production asset's compute logic without dirtying downstreams.

## What it does

Executes the asset's compute function. On dry-run mode:

- The **return value is discarded** (IO manager not invoked).
- Asset yields `MaterializeResult(metadata={dry_run: true, elapsed_seconds, would_produce_bytes})`.
- Emits `AssetObservation` tagged `dry_run=true`.
- Downstreams read via IO manager still see the last non-dry-run value.

## Enable modes

Priority order (highest wins):

1. Explicit `dry_run(enabled=True)` decorator arg / `enabled: true` YAML.
2. Run tag `dry_run` in `("true", "1", "yes")`.
3. Env var `DAGSTER_DRY_RUN` in `("true", "1", "yes")`.
4. Default: disabled.

## Why this belongs in Dagster

- **Run-tag enable** — flip dry-run on a single run from the UI/CLI without redeploy.
- **AssetObservation with dry_run tag** — every dry run is a queryable event.
- **Materialization result surfaces the mode** — Dagit shows `dry_run: True` prominently on that materialization.
- **Composes with the rest of the decorator stack** — dry runs still respect `@sla`, `@throttle`, `@smart_retry`, `@lifecycle` audits.

## Full YAML example

```yaml
type: dagster_community_components.DryRunAssetComponent
attributes:
  asset_name: costly_report

  compute:
    kind: python
    python: "my_project.reports:build_costly"

  # enabled: null   # (default) read run tag `dry_run` or env DAGSTER_DRY_RUN
```

## `@dry_run` decorator

```python
import dagster as dg
from dagster_community_components import dry_run

@dg.asset
@dry_run()  # enable via run tag `dry_run=true` or env DAGSTER_DRY_RUN=1
def costly_report(context):
    return build_report()
```

Launch a dry run from CLI:

```bash
dg launch --assets costly_report --tag dry_run=true
```

Or from Python:

```python
dg.materialize([costly_report], tags={"dry_run": "true"})
```

## Composes with

- **`@sla`** — SLA still fires; useful for validating duration regressions.
- **`@throttle`** — throttled dry runs still emit `throttle_skipped` observations.
- **`@smart_retry`** — retries within a dry run.
- **`@lifecycle`** — dry-run mode skips publish; audit still runs.
- **`@profile`** — profile a candidate output before committing.

## What's not in v1 (roadmap)

- **Cost-estimate hook** — inject a cost model so dry runs surface `estimated_cost_usd`.
- **Diff vs. current** — automatically diff the discarded output against the current committed asset.
- **Per-partition dry-run** — mask specific partitions from a dry run while committing others.
