# Lambda Invoke

Invoke an AWS Lambda function as a Dagster asset.

`RequestResponse` (the default) invokes synchronously and returns the function's JSON response as `response_payload` in the asset's output metadata. `Event` invokes asynchronously and fire-and-forgets -- AWS returns immediately with no payload to parse.

By default a Lambda-side error (`FunctionError` in the real boto3 response -- the function raised/returned an error, not a transport failure) fails the Dagster run with the function's `errorMessage` surfaced in the exception. Set `fail_on_function_error: false` to treat it as a materialized-but-errored result instead.

## Example YAML

```yaml
type: dagster_component_templates.LambdaInvokeAssetComponent
attributes:
  asset_name: score_transaction
  function_name: fraud-scoring-fn
  region_name: us-east-1
  payload_template: |
    {"transaction_id": "{{ partition_key }}"}
  partition_type: cron
  partition_start: '2024-01-01'
  partition_cron_schedule: '0 0 * * 1-5'
  group_name: risk
  kinds: [aws, lambda]
```

## Authentication

Uses the standard boto3 credential chain (env vars, shared config/credentials file, instance/task role). Set `aws_profile` to use a named profile instead of the default.

## Requirements
