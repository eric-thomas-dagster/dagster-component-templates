# `LogPrintsAssetComponent` + `@log_prints` decorator

Capture `print()` calls inside compute and route them to `context.log.info`. Every print becomes a real Dagster log event — searchable, timestamped, respected by the run monitor.

**Stolen from Prefect's `@flow(log_prints=True)`.** Useful for:
- Porting legacy scripts that use `print()` for visibility.
- Capturing third-party stdout that would otherwise disappear (pandas warnings, requests redirects, tqdm progress bars).

## Two shapes

| Shape | Use when |
|---|---|
| **`LogPrintsAssetComponent`** (YAML) | New print-capturing asset |
| **`@log_prints` decorator** (Python) | Wrap an existing `@dg.asset` |

## How it works

Wraps compute with `contextlib.redirect_stdout(sink)`. The sink is a custom `io.TextIOBase` that:
- Buffers stdout writes
- Splits on newlines
- Emits each non-empty line as `context.log.info(prefix + line)`

Original `sys.stdout` is restored after compute completes (success or failure).

## Full YAML example

```yaml
type: dagster_community_components.LogPrintsAssetComponent
attributes:
  asset_name: porting_script

  compute:
    kind: python
    python: "my_project.legacy:process_batch"

  prefix: "[print] "     # prepended to every captured line
```

## `@log_prints` decorator

```python
import dagster as dg
from dagster_community_components import log_prints

@dg.asset
@log_prints(prefix="[print] ")
def porting_script(context):
    print("Starting job")
    print(f"Processed {n} rows")
    return build()
```

Every `print()` line lands in the Dagster UI log panel + is searchable across runs via the event log.

## Composes with

Orthogonal to every other decorator. Stack it with `@smart_retry`, `@lifecycle`, `@sla`, etc., freely.

## What's not in v1 (roadmap)

- **stderr capture** — currently only stdout is redirected. Add `capture_stderr=True`.
- **Level routing** — parse line prefix like `WARN:` / `ERROR:` and route to `context.log.warning` / `context.log.error`.
