# Pub/Sub Subscription Asset

Ensures a Google Cloud Pub/Sub subscription on a topic is present or absent (the Airflow `PubSubCreateSubscriptionOperator` / `PubSubDeleteSubscriptionOperator` equivalent).

Idempotent: `create_subscription`/`delete_subscription` raise `AlreadyExists`/`NotFound` rather than silently no-op'ing, so this component catches those and reports `action: "none"` instead of failing. Omitting `push_endpoint` creates a pull subscription (the common case when a downstream Dagster sensor/asset pulls messages itself); setting it creates a push subscription. Distinct from `GooglePubSubComponent` (`integrations/google_pubsub`), which only observes pre-existing topics/subscriptions as read-only assets -- this component actually creates and deletes them.

## Example YAML

```yaml
type: dagster_community_components.PubsubSubscriptionAssetComponent
attributes:
  asset_name: orders_worker_subscription
  project_id: my-gcp-project
  topic_id: orders
  subscription_id: orders-worker
  credentials_env_var: GOOGLE_APPLICATION_CREDENTIALS
  desired_state: present
  ack_deadline_seconds: 30
  deps:
    - orders_topic
  group_name: infrastructure
```

## Authentication

Uses Application Default Credentials by default. Set `credentials_env_var` to an environment variable holding the path to a GCP service account JSON file instead.
