# Pub/Sub Topic Asset

Ensures a Google Cloud Pub/Sub topic is present or absent (the Airflow `PubSubCreateTopicOperator` / `PubSubDeleteTopicOperator` equivalent).

Idempotent: `create_topic`/`delete_topic` raise `AlreadyExists`/`NotFound` rather than silently no-op'ing, so this component catches those and reports `action: "none"` instead of failing. Distinct from `GooglePubSubComponent` (`integrations/google_pubsub`), which only observes pre-existing topics/subscriptions as read-only assets -- this component actually creates and deletes them.

## Example YAML

```yaml
type: dagster_community_components.PubsubTopicAssetComponent
attributes:
  asset_name: orders_topic
  project_id: my-gcp-project
  topic_id: orders
  credentials_env_var: GOOGLE_APPLICATION_CREDENTIALS
  desired_state: present
  labels:
    team: data-platform
  message_retention_duration_seconds: 86400
  group_name: infrastructure
```

## Authentication

Uses Application Default Credentials by default. Set `credentials_env_var` to an environment variable holding the path to a GCP service account JSON file instead.
