# ChurnZero Accounts Ingestion

Fetch ChurnZero Account records (churn scores, renewal/billing attributes) via ChurnZero's OData-flavored REST API and materialize the result as a pandas DataFrame.

Uses:
- `GET {base_url}/public/v1/Account` — OData-paginated list of Accounts

## Installation

```bash
pip install requests pandas
```

Also requires a `ChurnZeroResourceComponent` on the same code location for authentication (see `resources/churnzero_resource`).

## Output Schema

The DataFrame contains every field ChurnZero's `/public/v1/Account` returns for your tenant, including churn score and billing/renewal attributes (exact shape varies by account configuration).

## ChurnZero API notes

- **Base URL is account-specific, not a shared domain.** Each ChurnZero tenant has its own API host (some tenants are pinned to dedicated/region-specific hosts); you must find your exact `base_url` on the Application Key page under Admin -> API Keys. See `resources/churnzero_resource`.
- **Auth is HTTP Basic**: your login email + API key, base64-encoded.
- **Pagination follows OData convention**: the first page uses `$top`/`$filter`/`$orderby`; subsequent pages follow the `@odata.nextLink` absolute URL verbatim (via `ChurnZeroResource.get_url()`) rather than reconstructing query params.
- When a time-based `partition_type` is set, the partition window is translated into an OData `$filter` of the form `{date_field} ge {start} and {date_field} lt {end}`, combined with any static `filter_expr` via `and`.
