# Gainsight Company Ingestion

Fetch Gainsight Company records (health scores, CSM, stage, renewal) via Gainsight REST API v1 and materialize the result as a pandas DataFrame.

Uses:
- `POST /v1/data/objects/query/Company` — paginated query against the Company object (or any other object via `object_name`)

## Installation

```bash
pip install requests pandas
```

Also requires a `GainsightResourceComponent` on the same code location for authentication (see `resources/gainsight_resource`).

## Configuration

```yaml
type: dagster_component_templates.GainsightCompanyIngestionComponent
attributes:
  asset_name: gainsight_companies
  resource_key: gainsight_resource
  object_name: Company
  select_fields: ["Gsid", "Name", "Csm", "Status", "Stage", "Renewal_Date", "Health_Score"]
  limit: 2000
```

## Output Schema

The DataFrame contains exactly the fields listed in `select_fields` as columns (Gainsight's query API only returns selected fields, unlike a full-object GET).

## Gainsight API notes

- **Auth header is non-standard**: `accesskey` (not `Authorization: Bearer`/Basic). See `resources/gainsight_resource`.
- **Health score field names are org-specific.** Gainsight NXT computes health scores via a per-tenant Scorecard/Rules Engine, exposed as a custom field (commonly named something like `Health_Score__c`, but this varies by tenant). The default `select_fields` includes a placeholder `Health_Score` — confirm your org's actual field name via Gainsight Admin before relying on it.
- **Pagination is offset-based, not cursor-based**: each request specifies `limit`/`offset`; Gainsight's own docs note a 5000-record-per-request cap and recommend incrementing `offset` by the number of records actually returned.
- Company records aren't inherently time-partitioned data, so `from`/`to` semantics here are implemented as an optional `where` filter on `date_field` (default `Last_Modified_Date`) rather than a required time window like Gong's call-log pattern — set `modified_after`/`modified_before`, or a time-based `partition_type`, to use it; omit both to pull the full Company snapshot every run.
