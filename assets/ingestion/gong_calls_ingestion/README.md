# Gong Calls Ingestion

Fetch Gong call metadata and (optionally) transcripts via Gong API v2 and materialize the result as a pandas DataFrame.

Uses:
- `GET /v2/calls` — paginated list of call metadata for a date window
- `POST /v2/calls/transcript` — bulk transcript fetch for the returned call IDs

## Installation

```bash
pip install requests pandas
```

Also requires a `GongResourceComponent` on the same code location for authentication (see `resources/gong_resource`).

## Configuration

```yaml
type: dagster_community_components.GongCallsIngestionComponent
attributes:
  asset_name: gong_calls
  resource_key: gong_resource
  from_date_time: "2026-06-01T00:00:00Z"
  to_date_time: "2026-07-01T00:00:00Z"
  include_transcript: true
  limit: 500
```

## Output Schema

The DataFrame contains every field Gong's `/v2/calls` returns (varies by workspace) plus, when `include_transcript: true`:

- `transcript_raw` — the raw structured list-of-turns as returned by Gong
- `transcript` — a flattened `SPEAKER: text` newline-joined string suitable for LLM prompts (feed directly into `GongCallSummaryAssetComponent`)

## Gong API notes

- `/v2/calls/transcript` accepts up to 100 call IDs per request; this component chunks internally so `limit` may exceed 100.
- Pagination uses the `records.cursor` field; requests loop until the cursor is empty or `limit` is reached.
- Both `fromDateTime` and `toDateTime` must be ISO-8601 with timezone (Gong is strict — `Z` or `+HH:MM` required).
