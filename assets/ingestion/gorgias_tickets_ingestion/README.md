# Gorgias Tickets Ingestion

Fetch Gorgias support tickets via `GET /api/tickets` and materialize the result as a pandas
DataFrame.

Uses:
- `GET /api/tickets` — cursor-paginated list of tickets (`meta.next_cursor`)

## Installation

```bash
pip install requests pandas
```

Also requires a `GorgiasResourceComponent` on the same code location for authentication (see
`resources/gorgias_resource`).

## Configuration

```yaml
type: dagster_component_templates.GorgiasTicketsIngestionComponent
attributes:
  asset_name: gorgias_tickets
  resource_key: gorgias_resource
  from_date_time: "2026-06-01T00:00:00Z"
  to_date_time: "2026-07-01T00:00:00Z"
  order_by: "created_datetime:desc"
  limit: 500
```

## Gorgias API notes

- Pagination uses `meta.next_cursor` — requests loop until the cursor is empty, the page comes
  back empty, or `limit` is reached, whichever comes first. The per-request page size is capped
  at 100 by Gorgias regardless of `page_size`.
- **`/api/tickets` does not support server-side date-range filtering.** There is no
  `created_datetime[gte]`-style query param documented or supported. `from_date_time` /
  `to_date_time` are therefore applied as a **client-side filter** on the `created_datetime` field
  of the tickets already fetched — they narrow the output, not the API request. Set `order_by` and
  `limit` generously enough to actually cover your intended window.
- Rate limits: 40 requests / 20s for API-key integrations (see `resources/gorgias_resource`
  README for details). A full backfill of a large ticket volume may need multiple runs / a
  `limit` tuned to your rate budget.
