# Outreach Prospects Ingestion

Fetch Outreach Prospects via `GET /api/v2/prospects` and materialize the result as a pandas DataFrame.

Uses the `outreach_resource` component for authentication (see `resources/outreach_resource`).

## Installation

```bash
pip install requests pandas
```

Also requires an `OutreachResourceComponent` on the same code location for authentication (see `resources/outreach_resource`).

## Output Schema

The DataFrame has one row per prospect, with `id` and `type` columns plus
every field under the Outreach Prospect's `attributes` object flattened to
top-level columns (varies per org/custom-fields configuration — common ones
include `firstName`, `lastName`, `emails`, `title`, `company`, `createdAt`,
`updatedAt`). `relationships` (links to Account/Owner/Stage/Sequence records)
is dropped — this component ingests Prospect fields only, not relationship
linkage.

## Outreach API notes

- Outreach's API is [JSON:API](https://jsonapi.org/)-shaped: list responses
  return `{"data": [{"id", "type", "attributes", "relationships"}, ...], "links": {"next": "..."}}`.
  This component flattens `attributes` into columns for each row.
- Pagination is cursor-based via `links.next`, which is a complete URL
  (including its own `page[cursor]` querystring) — this component follows it
  directly rather than reconstructing query params itself.
- `page[size]` (page size) is capped at 1000 by Outreach.
- Auth is OAuth2 refresh_token grant, **not** Outreach's separate S2S
  app-install flow. See `resources/outreach_resource/README.md` for the
  refresh-token rotation gotcha (Outreach rotates the refresh_token on every
  exchange).
- Time filtering uses `filter[updatedAt][gt]` / `filter[updatedAt][lt]`
  (Outreach's bracket-operator filter syntax) rather than a single
  `fromDateTime`/`toDateTime` pair like Gong.
