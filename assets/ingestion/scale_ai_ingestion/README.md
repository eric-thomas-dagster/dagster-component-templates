# Scale AI Ingestion

Ingest Scale AI data-labeling task, batch, and project data using dlt's generic REST API source.

Uses dlt's generic REST API source (`dlt.sources.rest_api.rest_api_source`).

By default, runs an in-memory DuckDB pipeline and returns a pandas DataFrame. Set `destination` to persist directly to any dlt-supported destination. See `../DESTINATIONS.md`.

> **Note:** The `tasks` resource's response wraps records under a `"docs"` key (`{"docs": [...], "total": ..., "limit": ..., "has_more": ..., "next_token": ...}`) rather than returning a flat array -- this connector configures `data_selector: "docs"` to unwrap it. `batches` and `projects` are flat top-level arrays. Pagination differs per resource: `tasks` uses `limit` (1-100, default 100) + a `next_token` cursor; `batches` uses `limit`/`offset`; `projects` has no documented pagination. This connector does not implement explicit pagination params beyond what dlt's default paginator auto-detects from each response shape -- for high-volume task/batch extraction, verify dlt's auto-paginator is actually following `next_token`/`offset` as expected, and add an explicit paginator config if not.

> **Partition honesty note:** if you set `partition_type`, it controls Dagster's materialization/backfill schedule only. This connector's compute function does not use the partition key to filter the API request, so every partition run re-fetches the same full resource set rather than a bounded window.

| `resources` | optional | Comma-separated list of resources to extract: tasks, batches, projects. Default: `tasks,batches,projects` |
