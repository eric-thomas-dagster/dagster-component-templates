# Tavily Search Ingestion

Run search queries against [Tavily](https://tavily.com), an AI-native search API purpose-built
for RAG/agent pipelines (as opposed to a general web index like Google), and land the results as
flat rows: one row per (query, result).

Queries come from `queries` (a static comma-separated list), from an upstream asset's DataFrame
column (`upstream_asset_key` + `query_column`), or both -- when both are set, the static queries
and the per-row upstream queries are all run (deduplicated).

Output rows are shaped to feed `document_chunker` -> `vector_store_writer` directly: point
`document_chunker`'s `source_column` at `content` (the result's relevance-ranked text snippet),
and `metadata_columns` at `query,title,url,result_id` to preserve those through chunking.

> **Note:** Tavily also has a separate `/extract` endpoint (URL -> content, similar to
> `firecrawl_ingestion`/`jina_reader_ingestion`) -- this component is search-only and does not
> cover it.

By default, runs an in-memory DuckDB pipeline and returns a pandas DataFrame. Set `destination`
to persist directly to any dlt-supported destination. See `../DESTINATIONS.md`.

## Configuration

| Field | Required | Description |
|---|---|---|
| `asset_name` | required | Name of the asset that will hold the data |
| `api_key_env_var` | optional | Env var holding the Tavily API key. Default: `TAVILY_API_KEY` |
| `queries` | optional* | Comma-separated search queries. *At least one of `queries`/`upstream_asset_key` is required |
| `upstream_asset_key` | optional* | Upstream asset providing one search query per row (`query_column`) |
| `search_depth` | optional | `basic` (default) / `advanced` / `fast` / `ultra-fast` |
| `max_results` | optional | Results per query, 0-20. Default: `10` |
| `topic` | optional | `general` (default) / `news` / `finance` |
| `include_answer` | optional | `none` (default) / `basic` / `advanced` -- Tavily-generated LLM answer per query |
| `include_raw_content` | optional | `none` (default) / `markdown` / `text` -- full page content per result |

## Example
```yaml
type: dagster_community_components.TavilyIngestionComponent
attributes:
  asset_name: tavily_search_results
  api_key_env_var: TAVILY_API_KEY
  queries: "dagster asset checks, snowflake dynamic tables"
  search_depth: advanced
  max_results: 10
```
