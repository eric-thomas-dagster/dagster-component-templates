# `OpenSearchIndexUpsertComponent`

Reverse-ETL / search-index activation: sync an upstream DataFrame into an
**OpenSearch index** so warehouse-sourced data (product catalogs, content,
logs-as-search) powers site search. Uses OpenSearch's native Bulk API:

```
POST {host}/_bulk
Content-Type: application/x-ndjson

{"index": {"_index": "...", "_id": "..."}}
{...document...}
...
{"delete": {"_index": "...", "_id": "..."}}   (no source line after)
```

Each upstream row becomes one document: `id_field`'s value becomes the
`_id` in the action/metadata line (not part of the document source --
OpenSearch tracks `_id` separately), and every other upstream column
becomes a source field.

## Operations

| Operation | Bulk action | Behavior |
|---|---|---|
| `upsert` (default) | `index` | Create-or-replace in one call. |
| `delete` | `delete` | Remove the document. **No source line follows** the delete metadata line -- this is a hard requirement of the Bulk API spec. |

Both go through the same `/_bulk` endpoint, chunked at 1,000 rows per
HTTP request.

## When to use

- Sync a dbt/warehouse product or content catalog mart into OpenSearch
  for site search ("search-activation" reverse ETL).
- Keep a self-hosted or AWS OpenSearch index in lockstep with a
  source-of-truth table.
- Remove/suppress documents from search via `operation: delete`.

## Pairs with

- `opensearch_resource` -- host + basic-auth (primary case) or API key (required)

## Configuration

```yaml
type: dagster_component_templates.OpenSearchIndexUpsertComponent
attributes:
  asset_name: opensearch_product_catalog_sync
  upstream_asset_key: dbt_marts_product_catalog
  resource_key: opensearch_resource

  index_name: products
  id_field: product_id
  operation: upsert

  batch_size: 50000
  group_name: reverse_etl
```

## Partitioning

When `partition_type` is set, a run sends only the rows in its partition: `partition_date_column` selects the rows whose date falls in a time partition's window (a backfill run covers its whole range) and `partition_static_column` selects the rows for a static/dynamic partition key. Unpartitioned runs send every row.
