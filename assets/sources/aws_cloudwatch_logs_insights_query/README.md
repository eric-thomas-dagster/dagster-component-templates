## Partitioning

On a partitioned run the tokens `{partition_key}`, `{partition_date}`, `{partition_start}` and `{partition_end}` (and `{partition_<dimension>}` for multi-partitions) are substituted into `query_string`, so each partition reads its own slice. Unpartitioned runs use the value as written.
