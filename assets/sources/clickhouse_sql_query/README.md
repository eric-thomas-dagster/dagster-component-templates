# ClickHouse SQL Query

Executes a SQL query against [ClickHouse](https://clickhouse.com/)'s real HTTP interface (the query is sent as the raw POST body to `http://host:8123/`, with `FORMAT JSON` appended automatically) and materializes the result as a pandas DataFrame asset.

ClickHouse's own docs warn that a `200` status does not guarantee success -- it can start streaming a response before hitting an error mid-query. This component checks both failure modes: an upfront HTTP error (status >= 400, body is the error text) and a 200 response whose body isn't valid JSON (a mid-stream failure).

Plain HTTP+text API -- no native ClickHouse Python driver required.

## Example YAML

```yaml
type: dagster_community_components.ClickhouseSqlQueryComponent
attributes:
  asset_name: daily_pageviews
  host_url: http://clickhouse:8123
  query: |
    SELECT toDate(event_time) AS day, count() AS pageviews
    FROM analytics.events
    WHERE event_type = 'pageview'
    GROUP BY day
    ORDER BY day
  username: default
  password_env_var: CLICKHOUSE_PASSWORD
  group_name: analytics
  kinds: [clickhouse]
```
