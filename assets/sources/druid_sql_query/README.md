# Druid SQL Query

Executes a SQL query against an [Apache Druid](https://druid.apache.org/) broker's SQL HTTP API (`POST /druid/v2/sql`) and materializes the result as a pandas DataFrame asset.

Druid pairs naturally with Kafka/Flink pipelines in this registry: it's the real-time OLAP serving layer that answers "what did the stream just compute" with sub-second queries, where Kafka/Flink are the ingestion and processing layers.

Plain HTTP+JSON API -- no native Druid Python client required.

## Example YAML

```yaml
type: dagster_component_templates.DruidSqlQueryComponent
attributes:
  asset_name: daily_pageviews
  broker_url: http://druid-broker:8082
  query: |
    SELECT FLOOR(__time TO DAY) AS day, COUNT(*) AS pageviews
    FROM pageviews_datasource
    GROUP BY 1
  group_name: analytics
  kinds: [druid]
```

## Partition tokens

`{partition_key}`, `{partition_date}`, `{partition_start}`, `{partition_end}` are substituted into `query` on a partitioned run -- the same token convention as `trino_query`.

## Authentication

Set `username` + `password_env_var` for HTTP basic auth, or `request_headers` for a bearer token / custom header if the broker sits behind an authenticating proxy.
