# QuestDB SQL Query

Executes a SQL query against [QuestDB](https://questdb.com/)'s real HTTP REST API (`GET /api/v1/sql/execute`, with the query as a URL parameter) and materializes the result as a pandas DataFrame asset.

QuestDB's query endpoint is GET-only (a POST there returns `405`), and its `dataset` response field holds rows as positional value arrays, not column-keyed objects -- this component zips them against the `columns` field to build the DataFrame, so column order in the result always matches the query's own `SELECT` order rather than any assumption about field names.

Plain HTTP+JSON API -- no native QuestDB Python client required.

## Example YAML

```yaml
type: dagster_community_components.QuestdbSqlQueryComponent
attributes:
  asset_name: daily_sensor_readings
  host_url: http://questdb:9000
  query: |
    SELECT timestamp, sensor_id, avg(value) AS avg_value
    FROM sensor_readings
    SAMPLE BY 1d
  group_name: iot
  kinds: [questdb]
```
