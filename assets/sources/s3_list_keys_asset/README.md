# S3ListKeysAsset

List S3 object keys under a bucket/prefix as a Dagster asset — mirrors Airflow's `S3ListOperator`.

```yaml
type: dagster_community_components.S3ListKeysAssetComponent
attributes:
  asset_name: inbox_file_keys
  bucket: my-bucket
  prefix: inbox/
  delimiter: "/"
```

Metadata: `keys` (every key under `prefix`), `count`, and — only meaningful with `delimiter` set — `common_prefixes` (one level of "subfolder" names, matching boto3's real `list_objects_v2(Delimiter=...)` semantics, which Airflow's `S3ListOperator` exposes the same way).

Set `resource_key` to source credentials from a registered `aws_s3_resource` component instead of a bare `boto3.client("s3", region_name=...)`.

## `return_keys_as_value` — feed a downstream asset the key list directly

By default `keys` is only metadata. Set `return_keys_as_value: true` to also return it as this
asset's materialized value, so a downstream `python_callable_asset` (or any asset) can take it as
an input via `AssetIn`/`inputs` the usual way, instead of re-reading the metadata.
