# `Base64TransformComponent`

Base64 encode or decode one or more DataFrame columns — a StreamSets Base64-stage migration target. No other registry component does this (`text_codec_convert_asset` converts between character codecs like ASCII/EBCDIC, a different operation from base64).

## StreamSets compatibility notes

StreamSets' real Base64 processor works on **byte arrays only** — a string-typed field is a record error there, not silently accepted. This component matches that by default for `mode: encode` (`on_string_field: error`): encoding already-text data through base64 is almost always a sign an upstream step produced text where raw bytes were expected. Set `on_string_field: encode_utf8_first` to opt into the more lenient behavior (UTF-8 encode the string to bytes first, then base64-encode those bytes) for general ETL where the input genuinely is text. `mode: decode` always accepts a str or bytes column and always produces `bytes` output — there's no equivalent record-error case on decode.

StreamSets 6.x's Base64 stage takes a list of (origin field, result field) pairs so one stage call can transform several fields — `fields:` mirrors that shape.

## Example

```yaml
type: dagster_community_components.Base64TransformComponent
attributes:
  asset_name: payloads_encoded
  upstream_asset_key: payloads_raw
  mode: encode
  fields:
    - origin: payload_bytes
      result: payload_b64
    - origin: signature_bytes
      # result omitted -- overwrites signature_bytes in place
  url_safe: false
  group_name: transform
```

Decode example:

```yaml
attributes:
  mode: decode
  fields:
    - origin: payload_b64
      result: payload_bytes
```
