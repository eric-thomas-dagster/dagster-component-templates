# Field Merger Component

Merge one field's list/map value into another's, per row. Matches StreamSets' Field Merger processor: the `source_field` is **moved** (dropped from the output after merging, not copied), lists have the source's elements appended to the target's, and maps raise on a key that exists in both with a differing value — unless `on_key_conflict: overwrite`, where the source's value wins.

This component uses Dagster's IO manager to pass DataFrames between assets. No IO manager configuration is required for local development — Dagster's default FilesystemIOManager handles serialization automatically.

## Behavior

- Both `source_field` and `target_field` must be the **same kind** on every row — both lists or both maps. A mismatch (list vs. map, or either not list/map at all — e.g. a scalar) raises a clear error rather than silently coercing.
- **Lists**: `target + source` (target's elements first, then source's appended).
- **Maps**: a shallow merge; a key present in both with the *same* value is fine either way, but a key present in both with *different* values raises unless `on_key_conflict: overwrite` is set, in which case the source's value wins.
- The output column is `target_field` (holding the merged result); `source_field` no longer exists in the output.

```yaml
type: dagster_community_components.FieldMergerComponent
attributes:
  asset_name: merged_customer_tags
  upstream_asset_key: raw_customer_tags
  source_field: extra_tags     # dropped from the output after merging
  target_field: tags           # holds the merged result
  on_key_conflict: error        # or 'overwrite' to let extra_tags win on a conflicting key
```

## SQL source

Instead of `upstream_asset_key`, set `source` to pull rows directly via SQL
-- no intermediate asset required:

```yaml
source:
  kind: warehouse_query
  resource_key: snowflake_resource   # or database_url_env_var: DATABASE_URL
  sql: "SELECT * FROM my_table"
```

Mutually exclusive with `upstream_asset_key` -- set exactly one. Works with
any resource exposing `.get_engine()` (SQLAlchemy), `.get_connection()`
(DBAPI -- Postgres/Snowflake/DuckDB/MySQL/Databricks SQL), or `.get_client()`
(BigQuery, Redshift).
