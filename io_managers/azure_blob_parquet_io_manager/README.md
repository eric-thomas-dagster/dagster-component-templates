# AzureBlobParquetIOManager

ConfigurableIOManager that writes pandas DataFrames as Parquet to an Azure Blob Storage container. Asset path becomes the blob path; supports partitioned assets.

## Partition ranges (single_run backfills)

For an asset with `BackfillPolicy.single_run()`, one run covers a range of partitions. In that case the asset must return a dict `{partition_key: DataFrame}` whose keys are exactly the range's partition keys; each entry is written to its own per-partition blob (same layout as a single-partition run). Loading an upstream range returns `{partition_key: DataFrame}`. Anything else raises a clear `TypeError`/`ValueError`. Single-partition and unpartitioned behaviour is unchanged.
