# S3CsvIOManager

ConfigurableIOManager that writes pandas DataFrames as CSV to S3. Slower / lossier than the Parquet variant but readable from any tool. Supports partitioned assets and S3-compatible endpoints (MinIO, LocalStack).

## Partition ranges (single_run backfills)

For an asset with `BackfillPolicy.single_run()`, one run covers a range of partitions. In that case the asset must return a dict `{partition_key: DataFrame}` whose keys are exactly the range's partition keys; each entry is written to its own per-partition object (same layout as a single-partition run). Loading an upstream range returns `{partition_key: DataFrame}`. Anything else raises a clear `TypeError`/`ValueError`. Single-partition and unpartitioned behaviour is unchanged.
