# S3 Observation Sensor

Periodically connects to S3 and records an `AssetObservation` on the target external asset — surfacing health metrics in the Dagster UI without triggering a pipeline run.

## What this does

On each sensor tick, this component:
1. Connects to S3 using the provided credentials
2. Queries the resource for current health metrics
3. Records an `AssetObservation` on the target asset with the collected data -- ONLY when its `dagster/data_version` has changed since the last tick

Observations appear in the **Asset Activity** timeline, giving you a health history viewable in the Dagster UI.

## Change-only emission

A cursor (`{asset_key: last_seen_data_version}`, JSON-encoded) tracks the last observed DataVersion per target. A tick where nothing changed emits nothing -- not a materialization with an unchanged tag. Without this, any downstream freshness policy on the observed asset is meaningless: the asset would look fresh on every tick whether or not anything new actually landed.

## Multiple feeds from one instance

`targets:` declares several bucket/prefix feeds from one component instance -- one sensor, one poll tick, one boto3 client (or resource call) per tick -- instead of needing N component instances for N feeds. Mutually exclusive with the single-target `asset_key`/`bucket_name`/`prefix` fields (same convention as `external_sftp_path`'s `paths:`):

```yaml
type: dagster_community_components.S3ObservationSensorComponent
attributes:
  sensor_name: s3_feeds_observation
  resource_key: s3_obs
  targets:
    - asset_key: raw/orders
      bucket_name: my-data-bucket
      prefix: incoming/orders/
    - asset_key: raw/customers
      bucket_name: my-data-bucket
      prefix: incoming/customers/
```

## Example YAML
```yaml
type: dagster_community_components.S3ObservationSensorComponent
attributes:
  sensor_name: my_sensor_name
  asset_key: my_service/asset
  bucket_name: my_bucket_name
  # prefix: ""  # optional
  # region_name: None  # optional
  # check_interval_seconds: 300  # optional
  # resource_key: None  # optional
```

## Pair with the external asset

This sensor observes an external asset declared with `ExternalS3Asset`. Declare the external asset first:

```yaml
# 1. Declare the external asset
type: dagster_community_components.ExternalS3Asset
attributes:
  asset_key: external/s3

---

# 2. Observe it
type: dagster_community_components.S3ObservationSensorComponent
attributes:
  sensor_name: s3_observation_sensor_sensor
  asset_key: external/s3
```
