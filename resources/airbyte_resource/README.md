# Airbyte Resource

Register an Airbyte Cloud workspace (dagster-airbyte) for use by other components. This is specifically Airbyte Cloud (OAuth client-credentials auth against `api.airbyte.com`), not self-hosted/OSS Airbyte -- `airbyte_sync_sensor`'s inline fallback path (no resource_key set) targets the separate OSS Config API instead.

## Installation

`pip install dagster-airbyte`

## Fields

### Required

| Field | Type | Description |
|---|---|---|
| `workspace_id` | `str` | Airbyte Cloud workspace ID. |

### Connection

| Field | Type | Default | Description |
|---|---|---|---|
| `resource_key` | `str` | `"airbyte_resource"` | Key used to register this resource. Other components reference it via resource_key. |
| `client_id_env_var` | `str` | `"AIRBYTE_CLIENT_ID"` | Env var with the Airbyte client_id. |
| `client_secret_env_var` | `str` | `"AIRBYTE_CLIENT_SECRET"` | Env var with the Airbyte client_secret. |

## Configuration

```yaml
type: dagster_community_components.AirbyteResourceComponent
attributes:
  resource_key: airbyte_resource
  workspace_id: aaaabbbb-cccc-dddd-eeee-ffffffffffff
  client_id_env_var: AIRBYTE_CLIENT_ID
  client_secret_env_var: AIRBYTE_CLIENT_SECRET
```

## Usage in other components

```yaml
type: dagster_community_components.AirbyteSyncSensorComponent
attributes:
  sensor_name: airbyte_orders_sync_done
  connection_id: aaaabbbb-cccc-dddd-eeee-ffffffffffff
  resource_key: airbyte_resource
  job_name: process_synced_orders_job
```

## Authentication

Secret fields accept an **environment variable name** (not the secret value itself). Set it before running Dagster:

```bash
export AIRBYTE_CLIENT_SECRET="your-secret-here"
```
