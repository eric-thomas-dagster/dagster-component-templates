# Algolia Resource

Register an `AlgoliaResource` wrapping the Algolia Search REST API's write auth headers for use by other Dagster components.

## Installation

```bash
pip install requests
```

## Configuration

```yaml
type: dagster_component_templates.AlgoliaResourceComponent
attributes:
  resource_key: algolia_resource
  app_id: "YOUR_APP_ID"
  api_key_env_var: ALGOLIA_ADMIN_API_KEY
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: algolia_resource
```

Pairs with `AlgoliaIndexUpsertComponent` (`assets/reverse_etl/algolia_index_upsert`).

## Authentication

`api_key_env_var` accepts an **environment variable name** (not the key value itself):

```bash
export ALGOLIA_ADMIN_API_KEY="your-admin-api-key"
```

Use an **Admin API Key** (Dashboard -> Settings -> API Keys), not the
Search-only key -- batch/delete operations require write access. Avoid
embedding Admin keys client-side; this resource is intended for
server-side Dagster execution only.
