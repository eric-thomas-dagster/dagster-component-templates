# Athena Resource

Register an `AthenaResource` (Amazon Athena query + poll logic) for use by other components, ops, or assets.

This is the Airflow `AthenaOperator`'s real action -- `start_query_execution` + a poll loop to a terminal
state via `get_query_execution` -- extracted as a reusable `ConfigurableResource` rather than baked into a
dedicated asset. Call `run_query_and_wait(...)` from your own op or asset to run a query as a step in your
pipeline.

## Usage from your own op or asset

```python
import dagster as dg

@dg.asset
def my_athena_step(context: dg.AssetExecutionContext, athena_resource: "AthenaResource"):
    result = athena_resource.run_query_and_wait(
        query="SELECT count(*) FROM my_table",
        database="my_database",
        output_location="s3://my-bucket/athena-results/",
        log=context.log,
    )
    return result["data_scanned_bytes"]
```

Request it by `resource_key` the same way any other resource-providing component is referenced:

```yaml
attributes:
  resource_key: athena_resource
```
