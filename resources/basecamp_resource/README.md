# Basecamp Resource

Basecamp 3/4 REST API client wrapper — the unusual one in this repo's resource set.

- **Per-account URL, not a single host**: every request is scoped under `https://3.basecampapi.com/<account_id>/...`. The account ID is the numeric segment right after the host in any Basecamp URL, and is obtained once via `https://launchpad.37signals.com/authorization.json` post-OAuth (it is NOT part of the token response itself).
- **OAuth2 only**: there is no API-key option. The access token comes from a 3-legged authorization-code grant, done once outside this resource (e.g. a short setup script or the OAuth playground). Tokens expire (~2 weeks); this resource does not refresh them.
- **`User-Agent` convention**: Basecamp's docs ask integrations to self-identify with a descriptive `User-Agent` (app name + contact method) — a courtesy, not an enforced requirement.
