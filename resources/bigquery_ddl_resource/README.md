# BigQuery DDL Resource

Reusable BigQuery dataset/table lifecycle + scalar value-check actions, exposed as a Dagster `ConfigurableResource` -- the Airflow `BigQueryCreateEmptyDatasetOperator` / `BigQueryDeleteDatasetOperator` / `BigQueryCreateEmptyTableOperator` / `BigQueryDeleteTableOperator` / `BigQueryCheckOperator` / `BigQueryValueCheckOperator` equivalent.

An Airflow Operator is reusable action code, not itself a data asset -- this resource models that directly as callable methods any op or asset can use, rather than a dedicated asset per operator. Distinct from [`bigquery_resource`](../bigquery_resource/README.md), which just registers the official `dagster_gcp.BigQueryResource` (a raw client, no DDL/check convenience methods).

## Installation

`pip install google-cloud-bigquery`

## Usage in other components

Once placed on the canvas, other components (or your own custom op/asset code) can reference this resource:

```yaml
attributes:
  resource_key: bigquery_ddl_resource
```

```python
import dagster as dg

@dg.asset(required_resource_keys={"bigquery_ddl_resource"})
def my_asset(context: dg.AssetExecutionContext):
    ddl = context.resources.bigquery_ddl_resource
    ddl.ensure_dataset("analytics", location="US")
    ddl.ensure_table("analytics", "orders", table_schema=[
        {"name": "id", "type": "INTEGER", "mode": "REQUIRED"},
        {"name": "created", "type": "DATE"},
    ])
    result = ddl.run_value_check("SELECT COUNT(*) FROM analytics.orders", expected_value=0, comparison="greater_than")
    if not result["passed"]:
        raise dg.Failure(f"expected rows, got {result['actual_value']}")
```

### Methods

- `ensure_dataset(dataset_id, *, location=None, default_table_expiration_ms=None, default_partition_expiration_ms=None, labels=None, dataset_description=None)` -- idempotent create (`exists_ok=True`).
- `delete_dataset(dataset_id, *, delete_contents=False)` -- `delete_contents=False` (default) raises if the dataset still has tables.
- `recreate_dataset(dataset_id, *, delete_contents=False, **ensure_kwargs)` -- delete then re-create fresh.
- `ensure_table(dataset_id, table_id, table_schema, *, table_partition_field=None, table_partition_type="DAY", cluster_fields=None, expiration_ms=None, labels=None, table_description=None)` -- idempotent create; never alters an existing table's columns.
- `delete_table(dataset_id, table_id)`.
- `recreate_table(dataset_id, table_id, table_schema, **ensure_kwargs)` -- drop then re-create fresh.
- `run_value_check(query, expected_value, *, comparison="equal", tolerance=None, query_params=None)` -- returns `{actual_value, passed, rendered_query}`; raises `dg.Failure` if the query returns no rows. The caller decides whether `passed=False` should raise.

## Authentication

All secret fields accept an **environment variable name** (not the secret value itself).
Set the corresponding environment variable before running Dagster:

```bash
export GOOGLE_APPLICATION_CREDENTIALS="your-secret-here"
```
