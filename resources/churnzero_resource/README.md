## Authentication

ChurnZero uses HTTP **Basic auth**: your login email as the username, paired with an API key generated under **Admin -> API Keys** as the password.

```bash
export CHURNZERO_USERNAME="you@yourcompany.com"
export CHURNZERO_API_KEY="your-api-key"
```

## IMPORTANT: base URL is account-specific, not a shared domain

Unlike most SaaS APIs, ChurnZero does **not** have a single public API host. Each tenant's API lives at its own subdomain (and some tenants are pinned to dedicated/region-specific hosts), of the shape `https://{subdomain}.churnzero.net/public/v1/`. You must find your exact base URL on the **Application Key page** under **Admin -> API Keys** inside your own ChurnZero tenant -- it cannot be reliably derived from your tenant name alone. This resource therefore takes `base_url` as a plain required string rather than assembling it from a subdomain field.

## API notes

- Account records are exposed via an OData-flavored endpoint: `GET {base_url}/public/v1/Account`, supporting `$top` (page size, max 100), `$filter`, and `$orderby`. Pagination follows the `@odata.nextLink` field in each response.
- Used by the paired `ChurnZeroAccountsIngestionComponent` (see `assets/ingestion/churnzero_ingestion`) to ingest Accounts.
