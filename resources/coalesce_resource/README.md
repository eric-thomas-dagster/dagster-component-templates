# Coalesce Resource

Register a Coalesce Scheduler API resource for use by other components. The Scheduler API only supports starting a run and polling a specific run by its `runCounter` -- there is no endpoint to list or search runs by job/environment, so any consumer (like `coalesce_job_sensor`) must already know the `runCounter` it's polling.

## Configuration

```yaml
type: dagster_community_components.CoalesceResourceComponent
attributes:
  resource_key: coalesce_resource
  environment_id: my-env-id
  api_token_env_var: COALESCE_API_TOKEN
```

## Usage in other components

```yaml
type: dagster_community_components.CoalesceJobSensorComponent
attributes:
  sensor_name: coalesce_transform_done
  run_counter: "12345"
  resource_key: coalesce_resource
  job_name: downstream_processing_job
```

## Authentication

`api_token_env_var` accepts an **environment variable name** (not the secret value itself). Set it before running Dagster:

```bash
export COALESCE_API_TOKEN="your-token-here"
```
