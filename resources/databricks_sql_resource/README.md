# Databricks SQL Resource

Register a `databricks-sql-connector` connection to a Databricks SQL
Warehouse, for use by any component's `source: {kind: warehouse_query, ...}`
field.

**Not the same thing as `databricks_resource`.** That one wraps
`dagster_databricks.DatabricksClientResource` — job submission and cluster
management, with no SQL query capability at all. This component is
specifically for querying data: it wraps `databricks-sql-connector`, whose
connection object is DB-API 2.0 / PEP 249 compliant (confirmed against
Databricks' own docs), so it works directly with `pandas.read_sql()` —
the same `get_connection()` contract already used by `postgres_resource`,
`snowflake_resource`, `duckdb_resource`, and `mysql_resource`.

## Installation

`pip install databricks-sql-connector`

## Usage

Register this resource, then reference its `resource_key` from any
component's `source` field:

```yaml
type: dagster_component_templates.DatabricksSqlResourceComponent
attributes:
  resource_key: databricks_sql_resource
  server_hostname: dbc-a1b2345c-d6e7.cloud.databricks.com
  http_path: /sql/1.0/warehouses/a1b234c567d8e9fa
  access_token_env_var: DATABRICKS_SQL_TOKEN
```

```yaml
type: dagster_component_templates.HashComponent
attributes:
  asset_name: hashed_customers
  source:
    kind: warehouse_query
    resource_key: databricks_sql_resource
    sql: "SELECT * FROM main.sales.customers"
  columns: [email, phone]
```

`server_hostname` and `http_path` come from the SQL Warehouse's
**Connection Details** tab in the Databricks UI. `http_path` identifies a
specific warehouse — different warehouses have different paths even within
the same workspace.

## Fields

### Required

| Field | Type | Description |
|---|---|---|
| `server_hostname` | `str` | Databricks workspace hostname, e.g. 'dbc-a1b2345c-d6e7.cloud.databricks.com' (no scheme/path). |
| `http_path` | `str` | SQL Warehouse HTTP path, e.g. '/sql/1.0/warehouses/a1b234c567d8e9fa' (from the warehouse's Connection Details tab). |
| `access_token_env_var` | `str` | Env var holding a Databricks personal access token (or an OAuth token). Token-based auth only -- see the component docstring for scope. |

### Connection

| Field | Type | Default | Description |
|---|---|---|---|
| `resource_key` | `str` | `"databricks_sql_resource"` | Key used to register this resource. Other components reference it via resource_key. |
| `catalog` | `str` | — | Default Unity Catalog catalog for the connection. |

### Other

| Field | Type | Default | Description |
|---|---|---|---|
| `schema_name` | `str` | — | Default schema for the connection. |
