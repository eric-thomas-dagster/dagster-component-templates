# `DefaultResourceComponent`

Register a `DefaultResource` wrapping the [Default](https://default.com) (default.com) GTM/revenue-operations platform REST API for use by other Dagster components — workflow automation, lead routing, and scheduling.

## Installation

```bash
pip install requests
```

## Authentication

Confirmed against Default's real API reference docs (`https://docs.os.default.com/api-reference/`), not assumed:

- **Base URL:** `https://api.default.com`
- **Auth:** `Authorization: Bearer <api_key>` — plain API-key Bearer auth, **not** OAuth2.
- API keys carry scopes (e.g. `triggers:write`, `triggers:read`, `scheduling:read`, `scheduling:write`). Default returns `403 MISSING_SCOPE` if a key lacks the scope an endpoint needs.

`api_key_env_var` accepts an **environment variable name** (not the secret value itself):

```bash
export DEFAULT_API_KEY="sk_live_..."
```

Generate an API key in the Default app under API key management, and grant it the scope(s) your downstream components need.

## What this wraps

- `list_triggers()` — `GET /v1/triggers`
- `fire_trigger(trigger_id, email, responses=None, context=None)` — `POST /v1/triggers/{trigger_id}`
- `get_available_slots(event, start, end, reservation_id=None)` — `POST /v1/scheduling/events/{event}/slots`
- `book_meeting(event, start_time, reservation_id, person_email, **optional_fields)` — `POST /v1/scheduling/meetings`

Drop to `.get_client()` for anything not covered — returns an authenticated `requests.Session`.

## Error handling

Non-2xx responses raise `RuntimeError` with the HTTP status, Default's structured error `code` when present (e.g. `INVALID_API_KEY`, `MISSING_SCOPE`, `WORK_EMAIL_REQUIRED`, `RESERVATION_EXPIRED`, `RATE_LIMITED`), and the response body/message — never a bare status code.

## Example

```yaml
type: dagster_component_templates.DefaultResourceComponent
attributes:
  resource_key: default_resource  # key other components use
  api_key_env_var: DEFAULT_API_KEY  # env var holding your Default API key
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: default_resource
```

Pairs with `DefaultWorkflowTriggerComponent` (fire one API trigger per upstream row).
