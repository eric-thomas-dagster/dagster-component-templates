attributes:
  resource_key: drift_resource  # key other components use
  access_token_env_var: DRIFT_ACCESS_TOKEN  # env var holding your access token

## Authentication

The access token env var field accepts an **environment variable name** (not the token value itself).
Set the corresponding environment variable before running Dagster:

```bash
export DRIFT_ACCESS_TOKEN="ey...."
```

Drift issues two kinds of Bearer tokens:

- **Private app tokens** -- non-expiring, created under Drift Settings > App Marketplace > your
  private app. Recommended for server-to-server integrations like this one.
- **OAuth2 Authorization Code tokens** -- short-lived, obtained via the standard OAuth2 flow for
  public apps. This resource does not perform token refresh; mint and rotate the token externally
  if you use this flow.

All requests are sent to `https://driftapi.com` with header `Authorization: Bearer <token>`.
