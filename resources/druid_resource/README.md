# Druid Resource

Register an Apache Druid broker SQL HTTP API resource for use by other components.

[Apache Druid](https://druid.apache.org/) is reached over its broker's real SQL HTTP API (`POST /druid/v2/sql`), not a wire-protocol driver -- no native Druid Python client required.

## Installation

```
pip install requests
```

## Configuration

```yaml
type: dagster_community_components.DruidResourceComponent
attributes:
  resource_key: druid_resource
  broker_url: http://druid-broker:8082
  username: admin
  password_env_var: DRUID_PASSWORD
```

## Authentication

For brokers behind basic auth, set the password environment variable:

```bash
export DRUID_PASSWORD=your-password
```

Use `request_headers` instead if the broker sits behind an authenticating proxy expecting a bearer token or other custom header.

## Usage in other components

```yaml
attributes:
  resource_key: druid_resource
```

`druid_sql_query` reads credentials from this resource at run time when its own `resource_key` field is set, instead of redeclaring `broker_url`/`username`/`password_env_var` inline.

## Access shape

`DruidResource` exposes `query_url` (the base broker URL) and `execute_query(sql) -> List[Dict[str, Any]]` -- the same `POST /druid/v2/sql` call `druid_sql_query` makes inline, returning the JSON array of row objects.
