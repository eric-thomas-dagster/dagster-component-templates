# Fivetran Resource

Register a Fivetran workspace (dagster-fivetran) for use by other components.

## Installation

`pip install dagster-fivetran`

## Configuration

```yaml
type: dagster_community_components.FivetranResourceComponent
attributes:
  resource_key: fivetran_resource
  account_id: my_fivetran_account_id
  api_key_env_var: FIVETRAN_API_KEY
  api_secret_env_var: FIVETRAN_API_SECRET
```

## Usage in other components

```yaml
type: dagster_community_components.FivetranSyncSensorComponent
attributes:
  sensor_name: fivetran_orders_sync_done
  connector_id: my_connector_id
  resource_key: fivetran_resource
  job_name: process_synced_orders_job
```

## Authentication

Secret fields accept an **environment variable name** (not the secret value itself). Set them before running Dagster:

```bash
export FIVETRAN_API_KEY="your-key-here"
export FIVETRAN_API_SECRET="your-secret-here"
```
