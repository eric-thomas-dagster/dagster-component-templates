# Freshservice Resource

Register a `FreshserviceResource` for the Freshservice ITSM REST API (v2) for use by other Dagster components.

Freshservice is a **different Freshworks product from Freshdesk** -- an ITSM tool (tickets, assets, changes, requesters/agents) rather than a helpdesk/contacts tool. The auth shape is identical to Freshdesk (HTTP Basic, API key as username, literal `"X"` as password), but the API surface and the methods this resource exposes are Freshservice-specific.

## Configuration

```yaml
type: dagster_component_templates.FreshserviceResourceComponent
attributes:
  resource_key: freshservice_resource  # key other components use
  domain: mycompany.freshservice.com   # your Freshservice domain (full host)
  api_key_env_var: FRESHSERVICE_API_KEY  # env var holding your API key
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml

```

## Authentication

`api_key_env_var` accepts an **environment variable name** (not the secret value itself).
Set the corresponding environment variable before running Dagster:

```bash
export FRESHSERVICE_API_KEY="XXXXXXXXXXXXXXXXXXXX"
```

The resource provides a configured `requests.Session` via `get_session()` using HTTP Basic Auth `(api_key, "X")` against `https://{domain}/api/v2`. Find your API key in Freshservice under Profile Settings.

## Methods

This is the one external-call boundary other components (e.g. `freshservice_ticket_upsert`) mock in tests:

- `create_ticket(fields: dict) -> dict` -- `POST /api/v2/tickets`, returns the `ticket` object.
- `update_ticket(ticket_id, fields: dict) -> dict` -- `PUT /api/v2/tickets/{ticket_id}`, returns the `ticket` object.
- `filter_tickets(query: str) -> list[dict]` -- `GET /api/v2/tickets/filter` using the [Filter Tickets API](https://api.freshservice.com/#filter_tickets) syntax (e.g. `"unique_external_id:'ABC-123'"`), returns the `tickets` list. **Note**: date-type custom fields cannot be filtered this way -- a documented Freshservice limitation.

## Freshservice vs Freshdesk

| | Freshdesk | Freshservice |
|---|---|---|
| Product | Helpdesk / customer support | ITSM (IT service management) |
| Primary object | Contacts | Tickets (also: assets, changes, problems) |
| Match-by-external-id | `unique_external_id` contact filter param | No such field on tickets -- match via a custom field through the Filter Tickets API instead |
