## Authentication

Gainsight NXT uses a single **org-wide Access Key**, not per-user OAuth. Generate one under:

**Administration -> Connectors 2.0 -> Create Connection -> "Gainsight API" -> Authentication Type: Access_Key -> Generate Access Key**

The key is passed as the `accesskey` request header (a Gainsight-specific header name -- not `Authorization: Bearer` or Basic auth). It does not expire, but only one key can exist per org; regenerating it invalidates the old one everywhere.

```bash
export GAINSIGHT_ACCESS_KEY="your-access-key"
```

## API notes

- Gainsight's "Company" object query endpoint (`POST /v1/data/objects/query/Company`) is used by the paired `GainsightCompanyIngestionComponent` (see `assets/ingestion/gainsight_ingestion`).
- Health score is **not** a standard field name across Gainsight orgs -- it is almost always a custom field (e.g. `Health_Score__c` or similar), configured per-tenant in Gainsight's Scorecard/Rules Engine. Confirm your org's actual field name before relying on the ingestion component's default `select_fields`.
