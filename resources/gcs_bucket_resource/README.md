## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: gcs_bucket_resource
```

Or inject it directly into your own op/asset code:

```python
import dagster as dg
from resources.gcs_bucket_resource.component import GcsBucketResource

@dg.asset
def my_asset(gcs_bucket_resource: GcsBucketResource):
    gcs_bucket_resource.ensure_bucket("my-raw-landing-bucket", location="US", storage_class="STANDARD")
```

## Methods

- `create_bucket(bucket_name, location="US", storage_class="STANDARD", project=None)` -- expects the bucket NOT to already exist; raises `google.api_core.exceptions.Conflict` if it does. `project` overrides which GCP project owns/bills the bucket (defaults to the client's own project).
- `ensure_bucket(bucket_name, location="US", storage_class="STANDARD", project=None)` -- idempotent: a no-op if the bucket already exists and is owned by the caller. Returns `{"already_existed": bool}`.
- `delete_bucket(bucket_name, force=False)` -- idempotent: deleting an already-absent bucket succeeds. `force=True` empties the bucket first (not recommended by Google for buckets with more than ~256 objects). Returns `{"existed": bool, "objects_deleted": int}`.

## Authentication

All secret fields accept an **environment variable name** (not the secret value itself).
Set the corresponding environment variable before running Dagster:

```bash
export GCP_SERVICE_ACCOUNT_JSON_PATH="/path/to/service-account.json"
```

Unset, this resource uses GCP application-default credentials.
