# GCS Object Resource

Register a GcsObjectResource (upload/download/list/delete/exists for objects within a bucket) for use by other components -- fills the gap left by `gcs_resource` (raw client only) and `gcs_bucket_resource` (bucket lifecycle only).

## Installation

`pip install google-cloud-storage`

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: gcs_object_resource
```

Or inject it directly into your own op/asset code:

```python
import dagster as dg
from resources.gcs_object_resource.component import GcsObjectResource

@dg.asset
def my_asset(gcs_object_resource: GcsObjectResource):
    gcs_object_resource.upload("my-bucket", "path/to/obj.json", b'{"a": 1}', content_type="application/json")
    data = gcs_object_resource.download("my-bucket", "path/to/obj.json")
    names = gcs_object_resource.list_objects("my-bucket", prefix="path/")
```

## Methods

- `upload(bucket_name, blob_name, data, content_type=None)` -- upload raw string/bytes content, overwriting any existing object at that path.
- `upload_file(bucket_name, blob_name, local_path, content_type=None)` -- upload a local file's contents.
- `download(bucket_name, blob_name) -> bytes` -- download an object's content.
- `download_to_file(bucket_name, blob_name, local_path)` -- download an object's content directly to a local file.
- `list_objects(bucket_name, prefix=None) -> list[str]` -- list object names in a bucket, optionally filtered by prefix.
- `delete(bucket_name, blob_name, missing_ok=True) -> bool` -- delete an object. Idempotent by default (returns `False` if it didn't exist rather than raising); set `missing_ok=False` to raise `google.api_core.exceptions.NotFound` instead.
- `exists(bucket_name, blob_name) -> bool` -- whether an object exists.

## Authentication

All secret fields accept an **environment variable name** (not the secret value itself).
Set the corresponding environment variable before running Dagster:

```bash
export GCP_SERVICE_ACCOUNT_JSON_PATH="/path/to/service-account.json"
```

Unset, this resource uses GCP application-default credentials.
