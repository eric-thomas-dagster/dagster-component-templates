# Google Ads Resource

Register a `GoogleAdsResource` wrapping the official `google-ads` Python client for use by other Dagster components.

## Installation

```bash
pip install google-ads
```

## Configuration

```yaml
type: dagster_component_templates.GoogleAdsResourceComponent
attributes:
  resource_key: google_ads_resource
  developer_token_env_var: GOOGLE_ADS_DEVELOPER_TOKEN
  client_id_env_var: GOOGLE_ADS_CLIENT_ID
  client_secret_env_var: GOOGLE_ADS_CLIENT_SECRET
  refresh_token_env_var: GOOGLE_ADS_REFRESH_TOKEN
  customer_id: "1234567890"
  login_customer_id: "9876543210"  # only if customer_id is under an MCC
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: google_ads_resource
```

## Authentication

All secret env var fields accept **environment variable names** (not the secret values themselves).
Set the corresponding environment variables before running Dagster:

```bash
export GOOGLE_ADS_DEVELOPER_TOKEN="your-developer-token"
export GOOGLE_ADS_CLIENT_ID="xxxxx.apps.googleusercontent.com"
export GOOGLE_ADS_CLIENT_SECRET="xxxxxxxxxxxxxxxxxxxxxxxx"
export GOOGLE_ADS_REFRESH_TOKEN="1//xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

Apply for a developer token in the Google Ads UI (Tools & Settings → API Center),
create OAuth2 credentials in Google Cloud Console, and generate a refresh token
via the OAuth2 installed-app flow with scope `https://www.googleapis.com/auth/adwords`.
