## Configuration

```yaml
type: dagster_component_templates.GorgiasResourceComponent
attributes:
  resource_key: gorgias_resource  # key other components use
  subdomain: acme  # https://acme.gorgias.com
  email_env_var: GORGIAS_EMAIL  # env var holding the account email
  api_key_env_var: GORGIAS_API_KEY  # env var holding the REST API key
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_name: gorgias_resource
```

## Authentication

All secret env var fields accept **environment variable names** (not the secret values themselves).
Set the corresponding environment variables before running Dagster:

```bash
export GORGIAS_EMAIL="agent@acme.com"
export GORGIAS_API_KEY="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

Generate a personal REST API key from the Gorgias admin under **Settings > REST API**. The key
grants full account access and is used as the password half of HTTP Basic Auth (the account email
is the username). Resetting the key immediately invalidates the old one.

## Rate limits

Gorgias enforces 40 requests per 20-second window for API-key integrations (80/20s for OAuth2 apps,
same counts within a 10-second window for Enterprise accounts). A `429` response includes a
`Retry-After` header.
