# Linear Resource

Linear GraphQL API client wrapper. Personal API key or OAuth2 access token, sent **raw** (no `Bearer ` prefix) in the `Authorization` header — this is Linear's documented convention, unlike most APIs.

Linear has no REST surface at all; `.graphql()` is the one method every Linear component built against this resource uses, for both queries and mutations.
