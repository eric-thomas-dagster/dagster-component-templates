# Memcached Resource

Register a Memcached resource for high-performance in-memory caching.

A Dagster resource component that provides a Memcached `ConfigurableResource` backed by `pymemcache`.

## Installation

```
pip install "pymemcache>=4.0.0"
```

## Configuration

```yaml
type: memcached_resource.component.MemcachedResourceComponent
attributes:
  resource_key: memcached_resource
  host: memcached.internal
  port: 11211
```

## Pairs with

- `memcached_cache_flush` — flush the entire cache or delete a set of keys

## When to use

Memcached is best for **read-heavy, simple GET/SET** caching workloads without persistence, pub/sub, or complex data types. If you need any of persistence / streams / pub/sub / sorted sets / clustering, use `redis_resource` instead. If your app is already on Memcached, use this to invalidate + warm caches as part of a Dagster asset pipeline.
