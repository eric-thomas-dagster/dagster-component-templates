# OpenSearch Resource

Register an `OpenSearchResource` wrapping raw REST auth (basic auth or API key)
for the OpenSearch `_bulk` API, for use by other Dagster components.

## Installation

```bash
pip install requests
```

## Configuration

```yaml
type: dagster_component_templates.OpenSearchResourceComponent
attributes:
  resource_key: opensearch_resource
  host: "https://my-opensearch-domain.us-east-1.es.amazonaws.com"
  username_env_var: OPENSEARCH_USERNAME
  password_env_var: OPENSEARCH_PASSWORD
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: opensearch_resource
```

Pairs with `OpenSearchIndexUpsertComponent` (`assets/reverse_etl/opensearch_index_upsert`).

## Authentication

Basic auth (primary/default case):

```bash
export OPENSEARCH_USERNAME="admin"
export OPENSEARCH_PASSWORD="your-password"
```

Or an API key header (`Authorization: ApiKey ...`), when your deployment
is configured for it:

```bash
export OPENSEARCH_API_KEY="your-api-key"
```

Set `verify_ssl: false` only for self-signed dev clusters.
