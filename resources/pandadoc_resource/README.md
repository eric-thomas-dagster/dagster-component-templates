# PandaDoc Resource

Register a `PandaDocResource` wrapping PandaDoc's REST API (static API Key auth) for use by other Dagster components — specifically the write-side counterpart to `pandadoc_ingestion`, used by `pandadoc_document_create` to create and send documents from a template.

## Installation

```bash
pip install requests
```

## Authentication

PandaDoc uses a static **API Key**, sent as `Authorization: API-Key {key}` —
no OAuth flow, no token refresh. Generate one under PandaDoc Settings → API &
Integrations → API keys.

```bash
export PANDADOC_API_KEY="..."
```

## Document lifecycle

Document creation from a template is **asynchronous** on PandaDoc's side: a
freshly created document starts in a transient `document.uploaded` status
while PandaDoc builds it from the template, and only reaches `document.draft`
(sendable) once that processing completes. `wait_until_draft()` polls
`GET /documents/{id}` until the document is sendable (or a terminal error
status / timeout is hit) before `send_document()` is called.
