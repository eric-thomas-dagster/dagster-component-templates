# Pinot Resource

Register an Apache Pinot broker SQL HTTP API resource for use by other components.

[Apache Pinot](https://pinot.apache.org/) is reached over its broker's real SQL HTTP API (`POST /query/sql`), not a wire-protocol driver -- no native Pinot Python client required.

## Installation

```
pip install pandas requests
```

## Configuration

```yaml
type: dagster_community_components.PinotResourceComponent
attributes:
  resource_key: pinot_resource
  broker_url: http://pinot-broker:8099
  username: admin
  password_env_var: PINOT_PASSWORD
```

## Authentication

For brokers behind basic auth, set the password environment variable:

```bash
export PINOT_PASSWORD=your-password
```

Use `request_headers` instead if the broker sits behind an authenticating proxy expecting a bearer token or other custom header.

## Usage in other components

```yaml
attributes:
  resource_key: pinot_resource
```

`pinot_sql_query` reads credentials from this resource at run time when its own `resource_key` field is set, instead of redeclaring `broker_url`/`username`/`password_env_var` inline.

## Access shape

`PinotResource` exposes `query_url` (the base broker URL) and `execute_query(sql) -> pd.DataFrame` -- the same `POST /query/sql` call `pinot_sql_query` makes inline, including the same inline-`exceptions`-array check (Pinot can report a query error alongside an HTTP 200).
