## Configuration

```yaml
type: dagster_component_templates.PinterestAdsResourceComponent
attributes:
  resource_key: pinterest_ads_resource
  access_token_env_var: PINTEREST_ADS_ACCESS_TOKEN
  ad_account_id: "549756359984"
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: pinterest_ads_resource
```

## Authentication

`access_token_env_var` (and the optional `app_id_env_var` / `app_secret_env_var`)
accept **environment variable names** (not the secret values themselves):

```bash
export PINTEREST_ADS_ACCESS_TOKEN="pina_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

Pinterest Ads uses OAuth 2.0. Register an app at
[developers.pinterest.com](https://developers.pinterest.com/apps/), request
the `ads:read` and `ads:write` scopes, and complete the OAuth authorization
flow to obtain an access token scoped to your ad account. `app_id`/`app_secret`
are only needed if you plan to handle token refresh yourself; this resource
does not refresh tokens automatically.
