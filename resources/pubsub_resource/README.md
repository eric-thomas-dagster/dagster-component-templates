# Pub/Sub Resource

Register a reusable Google Cloud Pub/Sub topic/subscription lifecycle helper (create/delete, idempotent) for use by other components

An Airflow Operator is reusable action code (parameterized, callable from any task), which maps to a Dagster `ConfigurableResource`, not to an asset (which models persistent, lineage-tracked data). This resource is the Airflow `PubSubCreateTopicOperator` / `PubSubDeleteTopicOperator` / `PubSubCreateSubscriptionOperator` / `PubSubDeleteSubscriptionOperator` equivalent — call its methods from your own op or asset when you want the lifecycle action to participate in your pipeline, instead of installing a dedicated asset per lifecycle action.

## Usage from your own op/asset

```python
import dagster as dg

@dg.asset
def ensure_events_topic(pubsub_resource: PubsubResource) -> dg.MaterializeResult:
    result = pubsub_resource.ensure_topic(
        project_id="my-project",
        topic_id="events",
        message_retention_duration_seconds=86400,
    )
    return dg.MaterializeResult(metadata={"action": result["action"]})

@dg.asset(deps=[ensure_events_topic])
def ensure_events_subscription(pubsub_resource: PubsubResource) -> dg.MaterializeResult:
    result = pubsub_resource.ensure_subscription(
        project_id="my-project", topic_id="events", subscription_id="events-worker",
        ack_deadline_seconds=30,
    )
    return dg.MaterializeResult(metadata={"action": result["action"], "type": result["type"]})
```

Available methods:

- `ensure_topic(project_id, topic_id, labels=None, message_retention_duration_seconds=None)` — create the topic if missing (idempotent against `AlreadyExists`).
- `delete_topic(project_id, topic_id)` — delete the topic if present (idempotent against `NotFound`).
- `ensure_subscription(project_id, topic_id, subscription_id, ack_deadline_seconds=10, push_endpoint=None)` — create a pull subscription (default) or push subscription (when `push_endpoint` is set), idempotent against `AlreadyExists`.
- `delete_subscription(project_id, subscription_id)` — delete the subscription if present (idempotent against `NotFound`).

All four are idempotent: calling `ensure_*` a second time, or `delete_*` against something already gone, is a no-op rather than an error (the real `google-cloud-pubsub` client raises `AlreadyExists`/`NotFound` rather than silently no-op'ing — this resource catches both).

Distinct from `GooglePubSubComponent` (`integrations/google_pubsub`), which only *observes* pre-existing topics/subscriptions as read-only assets — this resource manages lifecycle (create/delete), not observation.

## Authentication

All secret fields accept an **environment variable name** (not the secret value itself).
Set the corresponding environment variable before running Dagster:

```bash
export GCP_SERVICE_ACCOUNT_JSON_PATH="/path/to/service-account.json"
```

If `credentials_env_var` is unset, Application Default Credentials are used.
