# QuestDB Resource

Register a QuestDB HTTP REST API resource for use by other components.

[QuestDB](https://questdb.com/) is reached over its real HTTP REST API (`GET /api/v1/sql/execute`), not a wire-protocol driver -- no native QuestDB Python client required.

## Installation

```
pip install pandas requests
```

## Configuration

```yaml
type: dagster_community_components.QuestdbResourceComponent
attributes:
  resource_key: questdb_resource
  host_url: http://questdb:9000
  username: admin
  password_env_var: QUESTDB_PASSWORD
```

## Authentication

For instances with built-in auth enabled, set the password environment variable:

```bash
export QUESTDB_PASSWORD=your-password
```

Use `request_headers` instead if QuestDB sits behind an authenticating proxy expecting a bearer token or other custom header.

## Usage in other components

```yaml
attributes:
  resource_key: questdb_resource
```

`questdb_sql_query` reads credentials from this resource at run time when its own `resource_key` field is set, instead of redeclaring `host_url`/`username`/`password_env_var` inline.

## Access shape

`QuestdbResource` exposes `query_url` (the base host URL) and `execute_query(sql) -> pd.DataFrame` -- the same `GET /api/v1/sql/execute` call `questdb_sql_query` makes inline, zipping the positional `dataset` rows against the `columns` field (QuestDB's query endpoint is GET-only; POST there returns 405).
