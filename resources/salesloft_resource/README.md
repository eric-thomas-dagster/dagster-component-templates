## Authentication

Salesloft supports two auth methods:

- **API key** (what this resource implements): a static Bearer token,
  passed as `Authorization: Bearer <api_key>`. Salesloft's docs state this
  method is "exclusively for customers" — current/future **partners** must
  build an OAuth2 app instead. For an internal pipeline reading your own
  org's data (the common Dagster use case), the API key is the simpler
  path and needs no token-refresh machinery (no expiry to track, unlike
  Outreach's OAuth tokens).
- **OAuth2** (Authorization Code or Client Credentials grant) — needed only
  if you're building a multi-tenant integration distributed to other
  Salesloft orgs. Not implemented by this resource; see
  [Salesloft's OAuth docs](https://developers.salesloft.com/docs/platform/api-basics/oauth-authentication/)
  if you need it.

```bash
export SALESLOFT_API_KEY="ak_..."
```

Generate an API key from Salesloft under Settings → API Key (customer
accounts) or via your admin.
