# SharePoint Resource

Register a SharePoint (Microsoft Graph) resource for use by other components. Requires an Azure AD app registration with `Sites.Read.All` (application) permission, admin-consented.

## Installation

`pip install requests`

## Configuration

```yaml
type: dagster_community_components.SharePointResourceComponent
attributes:
  resource_key: sharepoint_resource
  tenant_id_env_var: AZURE_TENANT_ID
  client_id_env_var: AZURE_CLIENT_ID
  client_secret_env_var: AZURE_CLIENT_SECRET
```

## Usage in other components

```yaml
type: dagster_community_components.SharePointMonitorSensorComponent
attributes:
  sensor_name: sharepoint_reports_monitor
  site_url: https://myorg.sharepoint.com/sites/DataTeam
  library_name: Reports
  resource_key: sharepoint_resource
  job_name: process_sharepoint_file_job
```

## Authentication

Secret fields accept an **environment variable name** (not the secret value itself). Set them before running Dagster:

```bash
export AZURE_CLIENT_SECRET="your-secret-here"
```
