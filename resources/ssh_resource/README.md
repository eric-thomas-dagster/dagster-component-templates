# SSH Resource

Register an `SSHResource` (run a command over a real `paramiko` SSH connection, returning
stdout/stderr/exit code) for use by other components, ops, or assets -- the reusable
operator logic behind the Airflow `SSHOperator` equivalent, injectable into any op/asset
rather than locked inside the single-purpose `ssh_asset`.

Reuses `ssh_asset`'s exact auth convention: `host_env_var`/`username_env_var` required;
auth via `private_key_path_env_var` (a key file already on disk, takes precedence),
`private_key_env_var` (PEM content, written to a secure temp file for the duration of the
connection), or `password_env_var` (fallback), in that order.

`run_command(command, timeout=None, environment=None, working_dir=None)` opens a fresh SSH
connection, runs one command, and returns `{"stdout": str, "stderr": str, "exit_code": int}`
-- it does **not** raise on a non-zero exit code, so the caller decides what counts as
failure. `environment` is applied via a safe `export K=V; ` shell prefix, not paramiko's own
`exec_command(environment=...)` kwarg (which silently does nothing unless the remote sshd's
`AcceptEnv` config explicitly allows each variable name).

## Example

```python
from dagster import asset

@asset
def my_asset(ssh_resource) -> None:
    result = ssh_resource.run_command("systemctl status myservice")
    if result["exit_code"] != 0:
        raise RuntimeError(f"command failed: {result['stderr']}")
```
