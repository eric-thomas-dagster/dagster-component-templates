# TikTok Ads Resource

Register a `TikTokAdsResource` for the TikTok Marketing API for use by other Dagster components.

## Installation

```bash

```

## Configuration

```yaml
type: dagster_component_templates.TikTokAdsResourceComponent
attributes:
  resource_key: tiktok_ads_resource
  access_token_env_var: TIKTOK_ADS_ACCESS_TOKEN
  advertiser_id: "1234567890123456789"
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_key: tiktok_ads_resource
```

## Authentication

`access_token_env_var` accepts an **environment variable name** (not the token value itself):

```bash
export TIKTOK_ADS_ACCESS_TOKEN="your-long-lived-access-token"
```

Create a TikTok for Business developer app at
[business-api.tiktok.com](https://business-api.tiktok.com), request Marketing
API access, and complete the OAuth authorization flow to obtain a long-lived
access token scoped to your advertiser account.
