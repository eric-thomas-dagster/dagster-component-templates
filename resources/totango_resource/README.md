## Configuration

```yaml
type: dagster_component_templates.TotangoResourceComponent
attributes:
  resource_key: totango_resource  # key other components use
  region: us  # or 'eu'
  app_token_env_var: TOTANGO_APP_TOKEN  # env var holding your service token
```

## Usage in other components

Once placed on the canvas, other components can reference this resource:

```yaml
attributes:
  resource_name: totango_resource
```

## Authentication

Generate a service token under **Settings -> Integrations -> API Token**. Totango uses a non-standard Authorization header value -- `app-token <token>`, not `Bearer` or Basic:

```bash
export TOTANGO_APP_TOKEN="your-service-token"
```

## API notes

- US tenants use `https://api.totango.com`; EU tenants use `https://api-eu1.totango.com`.
- Totango enforces a global rate limit of **100 calls/minute per token**.
- Used by the paired `TotangoAccountsIngestionComponent` (see `assets/ingestion/totango_ingestion`) to ingest Accounts via `POST /api/v1/search/accounts`.
