## Authentication

`api_token_env_var` accepts an **environment variable name** (not the secret value itself).
Set the corresponding environment variable before running Dagster:

```bash
export WORKABLE_API_TOKEN="XXXXXXXXXXXXXXXXXXXX"
```

The resource provides a configured `requests.Session` via `get_client()` using
`Authorization: Bearer <api_token>` against `https://{subdomain}.workable.com/spi/v3`.
Find your API token in Workable under Settings > Integrations > API Tokens.

## Methods

- `find_candidate_by_email(email)` -- `GET /candidates?email={email}` (exact-match filter).
- `create_job_candidate(shortcode, body)` -- `POST /jobs/{shortcode}/candidates`.
- `create_talent_pool_candidate(body)` -- `POST /talent_pool/candidates` (no job attached).
- `update_candidate(candidate_id, body)` -- `PATCH /candidates/{id}`.
- `move_candidate(candidate_id, member_id, target_stage)` -- `POST /candidates/{id}/move` (requires `member_id`, the acting Workable account member).
- `get_client()` -- escape hatch returning the authenticated `requests.Session`.
